# Yash Pandey — Portfolio & Engineering Showcase

A personal portfolio web application built with **React**, **TypeScript**, and **Tailwind CSS**. Designed around an editorial 60-30-10 daylight visual rhythm, featuring high-contrast typography, interactive project deep-dives, verified certifications, and direct communication channels.

🌐 **Live Application**: [https://yashpandey2211-a11y.github.io/Yash_Portfolio/](https://github.com/yashpandey2211-a11y/Yash_Portfolio)

---

## ✨ Features

- **Hero & Profile Overview**: Quick technical snapshot, academic highlights (SRM Institute of Science and Technology), and quick-action links.
- **Background & Trajectory**: Focused summary of research and development interests in Machine Learning, Deep Learning, Computer Vision, and full-stack software development.
- **Technical Toolset**: Structured display of languages, frameworks, cloud tooling, and developer environments.
- **Featured Projects**: Interactive project cards with deep-dive modal views, live demo links, repository access, and architectural summaries (e.g., *Automated License Plate Recognition*, *Handwritten Digit Recognition*, *Real-Time Face Mask Detection*).
- **Verified Certifications**: Z-pattern credential verification showcase for Microsoft Azure credentials on Credly.
- **Direct Messaging Form**: Integrated communication form dispatching submissions directly to email with live status confirmations and quick Gmail web launcher.
- **Responsive & Accessible**: Mobile-first fluid layout with full WCAG contrast compliance and keyboard navigation.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) and `npm` installed.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yashpandey2211-a11y/Yash_Portfolio.git
   cd Yash_Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) (or the port specified in your terminal) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
